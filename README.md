## 🚀 Funciones Game-Changer

### 🧠 Algoritmo de Matchmaking 2.0
No más dudas. Nuestro motor de compatibilidad calcula un **Match Score** en tiempo real comparando el perfil del contacto con tus preferencias personales (edad, ciudad, afinidad y flags).

### 🔐 Modo Ghost (Privacidad Total)
Seguridad de grado militar para tus contactos más discretos. Activa el **Ghost Mode** individualmente para requerir un PIN de acceso antes de revelar cualquier dato o foto.

### 🚩 Sistema de Banderas (Red & Green Flags)
Analiza a tus contactos con precisión quirúrgica. Añade listas detalladas de virtudes y defectos para que el algoritmo determine la viabilidad de la relación.

### 📊 Dashboard de Analytics
Visualiza el éxito de tu agenda con estadísticas globales. ¿Cuál es tu Match Score medio? ¿Qué porcentaje de éxito tienes? Todo en un panel de control unificado.

### 🎠 Explorador Visual
Navega por tu agenda con un estilo moderno de "tarjetas". Identifica rápidamente a tus contactos por su foto de perfil o localiza los perfiles protegidos por el candado de seguridad.

## 💻 Instalación y Ejecución

### 🍎 Para usuarios de macOS
1. **Descarga** el repositorio.
2. Abre la **Terminal** en la carpeta del proyecto.
3. Ejecuta el script de compilación automática:
   ```bash
   chmod +x run_mac.sh
   ./run_mac.sh
   ```
4. ¡Listo! Haz doble clic en `AgendasMatrimoniales.jar` para empezar.

### 🪟 Para usuarios de Windows (PC)
1. Asegúrate de tener instalado el [Java JDK](https://www.oracle.com/java/technologies/downloads/).
2. Haz doble clic en el archivo **`run_windows.bat`**.
3. Se abrirá una consola que compilará el código y generará el ejecutable automáticamente.
4. Una vez terminado, abre el archivo **`AgendasMatrimoniales.jar`**.

## ⚙️ Configuración Inicial
Al abrir la aplicación por primera vez:
1. Ve a la pestaña de **Configuración** ⚙️.
2. El PIN por defecto es **`0000`**.
3. Configura tu nombre, edad y preferencias de búsqueda para que el algoritmo empiece a trabajar para ti.
4. Cambia el PIN por uno secreto para asegurar tu privacidad.
