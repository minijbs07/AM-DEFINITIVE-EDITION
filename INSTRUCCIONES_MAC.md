# 🍎 Agendas Matrimoniales - Versión macOS

Este programa ha sido rediseñado para sentirse como una aplicación nativa de macOS (estilo Swift/SwiftUI).

## 🚀 Cómo ejecutarlo

### Método 1 (Recomendado): Doble Clic
1. Haz doble clic en el archivo `AgendasMatrimoniales.jar` que se encuentra en esta carpeta.
2. Si macOS te dice que no puede abrirlo por ser de un "desarrollador no identificado":
   - Haz **clic derecho** sobre el archivo y selecciona **Abrir**.
   - En el cuadro de diálogo que aparece, vuelve a pulsar **Abrir**.

### Método 2: Terminal
Si prefieres usar la terminal, ejecuta el script de arranque:
```bash
./run_mac.sh
```

## 🛠️ Novedades del Rediseño
- **Barra Lateral (Sidebar)**: Navegación intuitiva al estilo de las apps nativas de Apple (como Mail o Notas).
- **Tipografía Nativa**: Utiliza la fuente del sistema (.AppleSystemUIFont).
- **Layout Moderno**: Espaciado limpio, fondos claros y botones estilizados.
- **Icono en el Dock**: Ahora la aplicación muestra su icono personalizado en el Dock de macOS mientras está abierta.

## 💾 Persistencia
- Puedes guardar y cargar tus agendas desde el botón **"Cargar/Guardar"** de la barra lateral.
- Los archivos se guardan con total integridad de datos.
